# Sorting Algorithm Visualizer

An interactive dashboard that compares Bubble, Selection, Insertion, Quick, Merge and Heap sort.

## Features
- Live animated comparison of all six algorithms on the same array
- Performance table and charts (time, comparisons, swaps)
- Step-by-step walkthrough with pseudocode and flowchart
- Divide & conquer split tree for Merge and Quick sort
- Complexity growth chart (linear and log scale)

## Run locally
Open `index.html` in any browser. No install or build step needed.
